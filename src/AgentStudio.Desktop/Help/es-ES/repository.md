Esta pantalla cuenta qué pasó en el repositorio del proyecto. Solo lee: no cambia nada.

## Qué ves
- **El resumen:** la rama en la que estás, si hay cambios sin guardar y dónde se publica el repositorio.
- **Las ramas:** las tuyas y las que Agent Studio crea para cada ejecución.
- **Las versiones guardadas:** cada una dice quién la hizo. Si fue Agent Studio, dice la ejecución, la tarea, el intento, el agente y el modelo.
- **La actividad:** las integraciones y las entregas, y si salieron bien.

## Cómo leerlo
Agent Studio solo dice que hizo una versión si el registro lo respalda. Si no, a lo sumo la marca como **sugerencia**: puede ser verdad, pero nadie la ha confirmado.

## Consejos
- Si Agent Studio no lee el repositorio, la pantalla dice por qué.
- Filtra la actividad por ejecución, tarea, hito, agente o modelo.
