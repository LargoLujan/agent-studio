Esta pantalla cuenta qué pasó en el repositorio del proyecto. Sus cuatro primeras pestañas solo leen: no cambian nada.

## Qué ves
- **El resumen:** la rama en la que estás, si hay cambios sin guardar y dónde se publica el repositorio.
- **Las ramas:** las tuyas y las que Agent Studio crea para cada ejecución.
- **Las versiones guardadas:** cada una dice quién la hizo. Si fue Agent Studio, dice la ejecución, la tarea, el intento, el agente y el modelo.
- **La actividad:** las integraciones y las entregas, y si salieron bien. También lo que Agent Studio hizo en GitHub o vio allí, con su resultado real. Arriba va lo pendiente de sincronizar, con su motivo.
- **Las peticiones de fusión (PR):** las que sigues en GitHub y sus acciones. Lo explica el artículo «Publicar y abrir una petición de fusión (PR)».
- En las ramas de una ejecución verás si está publicada, en qué versión y si se borró en GitHub. Solo lo dice cuando el historial lo sabe.

## Cómo leerlo
Agent Studio solo dice que hizo una versión si el registro lo respalda. Si no, a lo sumo la marca como **sugerencia**: puede ser verdad, pero nadie la ha confirmado.

## Consejos
- Si Agent Studio no lee el repositorio, la pantalla dice por qué.
- Filtra la actividad por ejecución, tarea, hito, agente o modelo.
