The lock covers Agent Studio when you step away, without stopping the work in progress.

## How to use it
- Press **Lock** at the top, or use Ctrl+Alt+L.
- To come back, Windows asks you to confirm it is you (Hello or the Windows lock).

## What happens while it is locked
The agents keep working. Whatever needs your approval waits until you are back.

## Tips
- Set up Windows Hello in Windows so the confirmation is quick.
- Keyboard shortcuts stop working while it is locked.
