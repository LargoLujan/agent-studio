The monitor shows you what each agent is doing right now.

## What you see
- **The state of each task**: waiting, working, done or with problems.
- **The context**: how much of its working memory each agent has used. When it fills up, the agent starts to lose the thread.
- **Problems, Output and Tests**: the panels at the bottom. Problems says what failed and why; Output, what the agent writes; Tests, what was checked.

## When an agent asks you something
An agent may stop to ask you a question. You will see the question with the options and what each one costs. Answer when you can: meanwhile that agent waits.

## If the computer restarts
You can say beforehand whether the work resumes by itself. Settings and the monitor screen show it.
