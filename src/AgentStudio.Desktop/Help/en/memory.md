Memory keeps what the project has learned so the agents do not start from scratch.

## What it holds
Decisions, agreements and useful facts, each with its origin. What is not checked is marked as such.

## What you can do
- Search by words or by meaning.
- Review and correct what does not convince you.
- Read the **daily summary**, which tells in a few lines what happened.

## Tips
- An agent only reads the memory its card allows.
- Memory never leaves your computer except what you send to an agent.
