# Respuestas de ejemplo de la API de GitHub (escritas a mano)

Estas respuestas **no se grabaron de GitHub**: se escribieron a mano a partir de la documentacion oficial de la API REST
(GET /repos/{owner}/{repo} y GET /repos/{owner}/{repo}/commits) y solo llevan la forma que lee el doctor de skills, mas
algunos campos de relleno y direcciones que el doctor **no** debe seguir. Ninguna prueba toca la red. Una prueba en vivo,
con permiso expreso, queda pendiente (docs/20 seccion 12).
