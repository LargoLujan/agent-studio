## 1. Estándar Agent Skills

- **V** — Formato abierto creado por Anthropic: carpeta con `SKILL.md` obligatorio y `scripts/`, `references/`,
  `assets/` opcionales. https://agentskills.io/specification · repo `agentskills/agentskills` (Apache-2.0).
- **V** — Frontmatter obligatorio: `name` (≤ 64, `[a-z0-9-]`, igual que la carpeta) y `description` (≤ 1024).
  Opcionales: `license`, `compatibility`, `metadata` (mapa texto→texto), `allowed-tools` (experimental).
- **V** — Carga progresiva: metadatos (~100 tokens) al arrancar; cuerpo al activarse (recomendado < 5 000 tokens y
  < 500 líneas); recursos bajo demanda. Validador: `skills-ref validate`.
- **V** — Adoptado por Claude Code, Codex, Gemini CLI, GitHub Copilot, VS Code, Cursor y otros.

## 2. Claude Code (2.1.290)

- **V** — Ubicaciones: `~/.claude/skills/`, `.claude/skills/` del proyecto (y anidadas), `.claude/skills/` de
  directorios pasados con `--add-dir`, y `skills/` de plugins (espacio de nombres `plugin:skill`).
  https://code.claude.com/docs/en/skills
- **V** — Activación: `skillOverrides` en settings (`on`, `name-only`, `user-invocable-only`, `off`; no afecta a
  plugins), reglas de permisos `Skill(nombre)`, `--disable-slash-commands` (desactiva todas), `enabledPlugins`.
- **V** (ayuda local) — `--plugin-dir <ruta>` carga un plugin solo para esa sesión; `--setting-sources`; `--settings`.
  `claude plugin details` muestra componentes y coste estimado en tokens; `claude plugin validate`.
- **I** — Por ejecución, sin tocar la configuración global: un directorio temporal con forma de plugin
  (`skills/<n>/SKILL.md` + `plugin.json` mínimo) pasado con `--plugin-dir`. **NV**: si `--setting-sources` excluye
  también `~/.claude/skills`.

## 4. Gemini CLI (0.64.0, instalado)

## 6. Salud verificable

- **V** — API REST de GitHub: 60 peticiones/h sin autenticar, 5 000/h con token. `GET /repos/{o}/{r}` da `archived`,
  `pushed_at`, `license.spdx_id`, `default_branch`, `stargazers_count`.
- **V** — `GET /repos/{o}/{r}/compare/{sha}...{rama}` da `ahead_by` y `files[]`: si algún fichero bajo la carpeta de
  la skill cambió desde el commit fijado, hay actualización pendiente de revisar.
- **I** — `ETag`/`If-None-Match` para ahorrar cuota.

## 7. Seguridad

- **V** — Anthropic: usar solo fuentes de confianza; una skill maliciosa puede dirigir al agente a ejecutar código o
  exfiltrar datos; auditar todos los ficheros; las que descargan URLs externas son especialmente arriesgadas.
  https://platform.claude.com/docs/en/agents-and-tools/agent-skills/overview#security-considerations
- **V** — Claude Code: `disableSkillShellExecution` en settings; las skills pueden declarar `hooks` y `allowed-tools`.
- **V** — `gemini skills install` pide consentimiento salvo `--consent`.
- **NV** — Guía oficial de seguridad de skills para Codex.
